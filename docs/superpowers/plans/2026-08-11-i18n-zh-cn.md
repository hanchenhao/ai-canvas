# NodeTool 中文化（i18n）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 NodeTool 的 Web 应用支持简体中文与英文，用户可在设置页切换；默认跟随系统语言。

**Architecture:** `react-i18next` 处理 UI 文案；节点库（title/description/属性字段）通过集中翻译表在 web 客户端元数据访问层做翻译（web 不直接持有 NodeRegistry，而是通过 `/api/nodes/metadata` 拉取到 `useMetadataStore`）；新增 `useTranslatedNodeMetadata` hook 包装原 store，在 render sites 替换访问点；用户语言选择持久化到现有 `SettingsStore`。

**Tech Stack:** React 19.2 + TypeScript 5.9 + MUI 7.3 + Zustand 5 + react-router-dom 7 + Jest 29 + Testing Library 16；新增 `i18next` + `react-i18next`。

## Global Constraints

- **Node.js 22.22.1**（项目 `.nvmrc` 强制）。每次代码改动后跑：`npm run typecheck`、`npm run lint`、`npm run test`。
- **UI Primitives 强制策略**：所有新 UI 必须用 `web/src/components/ui_primitives/` 的 primitives（`SelectField`、`Text`、`FlexColumn`、`Box`、`Tooltip` 等），禁止直接用 MUI 裸组件。
- **Design tokens**：禁止硬编码字号（`"14px"`）、间距（`5px`）、圆角（`4`）、过渡（`"all 200ms ease"`）；用 `ui_primitives` 的 `SPACING` / `TYPOGRAPHY` / `BORDER_RADIUS` / `MOTION`。
- **测试框架**：Jest 29，测试文件与源码同目录，命名 `*.test.ts(x)`。运行命令：`TZ=UTC npx jest --forceExit`（在 `web/` 下）。
- **类型严格**：strict mode、禁止 `any`、`const` 默认。
- **专有名词译法**：参考 `docs/superpowers/specs/2026-08-11-i18n-zh-cn-design.md` 的术语表。无标准中译的（API/MCP/WebSocket/OAuth/GPU/LLM/JSON/Markdown/SDK）保留英文。
- **提交前**：跑 `npm run typecheck && npm run lint`。Pre-commit 失败时不要 `--no-verify`，修复后重新提交。
- **不要修改与本任务无关的文件**。工作树目前有未提交改动（`.env.example`、`package-lock.json`、`web/src/index.tsx`、`web/src/studio/*`），不属于本计划；除非本计划明确指示，否则不动它们。

```ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import LanguageDetector from "i18next-browser-languagedetector";

import enCommon from "../locales/en/common.json";
import enSettings from "../locales/en/settings.json";
import enNodes from "../locales/en/nodes.json";
import enErrors from "../locales/en/errors.json";
import zhCommon from "../locales/zh-CN/common.json";
import zhSettings from "../locales/zh-CN/settings.json";
import zhNodes from "../locales/zh-CN/nodes.json";
import zhErrors from "../locales/zh-CN/errors.json";

export const SUPPORTED_LANGUAGES = ["auto", "en", "zh-CN"] as const;
export type Language = (typeof SUPPORTED_LANGUAGES)[number];

export const FALLBACK_LANGUAGE = "en";

void i18n
  .use(initReactI18next)
  .use(LanguageDetector)
  .init({
    resources: {
      en: {
        common: enCommon,
        settings: enSettings,
        nodes: enNodes,
        errors: enErrors
      },
      "zh-CN": {
        common: zhCommon,
        settings: zhSettings,
        nodes: zhNodes,
        errors: zhErrors
      }
    },
    fallbackLng: FALLBACK_LANGUAGE,
    interpolation: { escapeValue: false },
    detection: {
      order: ["localStorage", "navigator"],
      lookupLocalStorage: "i18n-lang",
      caches: ["localStorage"]
    }
  });

export default i18n;
```

- [ ] **Step 5: 写 I18nProvider 组件**

`web/src/i18n/I18nProvider.tsx`：

```tsx
import { useEffect, type ReactNode } from "react";
import { I18nextProvider } from "react-i18next";
import i18n from "./index";
import { useSettingsStore } from "../stores/SettingsStore";
import { FALLBACK_LANGUAGE, type Language } from "./index";

function resolveLanguage(setting: Language): string {
  if (setting !== "auto") return setting;
  const nav = typeof navigator !== "undefined" ? navigator.language : "";
  return nav.toLowerCase().startsWith("zh") ? "zh-CN" : "en";
}

export function I18nProvider({ children }: { children: ReactNode }) {
  const language = useSettingsStore((state) => state.settings.language);

  useEffect(() => {
    const resolved = resolveLanguage(language);
    if (i18n.language !== resolved) {
      void i18n.changeLanguage(resolved);
    }
  }, [language]);

  return <I18nextProvider i18n={i18n}>{children}</I18nextProvider>;
}

export { FALLBACK_LANGUAGE };
```

注意：本任务引用 `state.settings.language`，该字段在 Task 3 加入 `SettingsStore`。**执行顺序建议**：先做 Task 3（加 `language` 字段），再做本任务的 Step 4-5（i18n init 和 Provider）。本任务 Step 1-3（locale JSON）和 Task 3 可以并行进行。最后合并 Task 2 + Task 3 为一个 commit 提交。

```tsx
import { useTranslation } from "react-i18next";
import { SelectField, FlexColumn, Text } from "../ui_primitives";
import { useSettingsStore } from "../../stores/SettingsStore";
import { SUPPORTED_LANGUAGES, type Language } from "../../i18n";

export function LanguageSelector() {
  const { t } = useTranslation();
  const language = useSettingsStore((s) => s.settings.language);
  const updateSettings = useSettingsStore((s) => s.updateSettings);

  return (
    <FlexColumn gap={SPACING.sm}>
      <Text size="small">{t("common:language.label")}</Text>
      <SelectField
        value={language}
        onChange={(e) => updateSettings({ language: e.target.value as Language })}
        options={SUPPORTED_LANGUAGES.map((l) => ({
          value: l,
          label: t(`common:language.${l === "auto" ? "auto" : l}`)
        }))}
      />
    </FlexColumn>
  );
}

// Local import — adjust path if SPACING lives elsewhere in ui_primitives
import { SPACING } from "../ui_primitives";
```

```ts
/**
 * Scans all registered node packages and dumps the user-facing strings
 * (title, description, property title, property description) per node type
 * to web/src/locales/en/nodes.json. That file is the source for translators;
 * the zh-CN counterpart is hand-translated.
 *
 * Run: `npx tsx scripts/extract-node-strings.ts`
 */
import { writeFileSync } from "node:fs";
import { resolve, dirname } from "node:path";
import { fileURLToPath } from "node:url";
import { NodeRegistry } from "../packages/node-sdk/src/registry.ts";
// Reuse the same setup the websocket server uses to register all packages.
import { setupNodeRegistry } from "../packages/websocket/src/node-registry-setup.ts";

const __dirname = dirname(fileURLToPath(import.meta.url));
const OUTPUT_PATH = resolve(
  __dirname,
  "..",
  "web",
  "src",
  "locales",
  "en",
  "nodes.json"
);

type PropertyStrings = {
  title?: string;
  description?: string;
};

type NodeStrings = {
  title: string;
  description: string;
  properties: Record<string, PropertyStrings>;
};

type NodeStringsCatalog = Record<string, NodeStrings>;

function extract(registry: NodeRegistry): NodeStringsCatalog {
  const all = registry.listMetadata();
  const catalog: NodeStringsCatalog = {};
  for (const meta of all) {
    const props: Record<string, PropertyStrings> = {};
    for (const p of meta.properties ?? []) {
      if (!p.name) continue;
      props[p.name] = {
        title: p.title,
        description: p.description
      };
    }
    catalog[meta.node_type] = {
      title: meta.title,
      description: meta.description,
      properties: props
    };
  }
  return catalog;
}

async function main() {
  const registry = await setupNodeRegistry();
  const catalog = extract(registry);
  // Sort keys for stable diffs.
  const sorted: NodeStringsCatalog = {};
  for (const key of Object.keys(catalog).sort()) {
    sorted[key] = catalog[key];
  }
  writeFileSync(OUTPUT_PATH, JSON.stringify(sorted, null, 2) + "\n", "utf8");
  console.log(`Wrote ${Object.keys(sorted).length} nodes to ${OUTPUT_PATH}`);
}

void main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```

**注意**：`setupNodeRegistry()` 是一个**待创建或重构**的工厂函数。`packages/websocket/src/node-registry-setup.ts` 当前可能直接 `export const nodeRegistry = new NodeRegistry()` 并在模块顶层执行注册——这会带来两个问题：本脚本 import 时会执行所有节点的注册副作用（可能拖慢或失败），并且函数签名不对。**改造步骤**：

1. 打开 `packages/websocket/src/node-registry-setup.ts`，找到现有 `new NodeRegistry()` 调用和后续 `registerPackage(...)` 调用。
2. 把它们包进一个新导出函数：

   ```ts
   export function setupNodeRegistry(): NodeRegistry {
     const registry = new NodeRegistry();
     // ... 所有现有的 registerPackage 调用，原封不动
     return registry;
   }
   ```

3. 把原 `export const nodeRegistry = new NodeRegistry()` 改为 `export const nodeRegistry = setupNodeRegistry()`（保持 websocket 启动路径不变）。
4. 在本脚本里 `import { setupNodeRegistry } from "../packages/websocket/src/node-registry-setup.ts"` 调用即可。

## Task 9: 创建 useTranslatedNodeMetadata hook

**Files:**
- Create: `web/src/hooks/useTranslatedNodeMetadata.ts`
- Test: `web/src/hooks/useTranslatedNodeMetadata.test.tsx`

**Interfaces:**
- Consumes: `useMetadataStore`（原 metadata），`useTranslation`（i18n）
- Produces:
  - `useTranslatedNodeMetadata(nodeType: string): NodeMetadata | undefined` — 单节点查询，返回带翻译的 shallow copy
  - `useAllTranslatedMetadata(): NodeMetadata[]` — 全部节点的翻译版本数组

**翻译策略**：对每个 `NodeMetadata`，按 `nodes:<node_type>.title` 查 i18n；命中则替换 title，未命中保持原值。`description` 同理。属性面板字段：按 `nodes:<node_type>.properties.<name>.title` 查。

`web/src/hooks/useTranslatedNodeMetadata.ts`：

```ts
import { useMemo } from "react";
import { useTranslation } from "react-i18next";
import useMetadataStore from "../stores/MetadataStore";
import type { NodeMetadata, PropertyMetadata } from "../stores/ApiTypes";

function translateProperty(
  prop: PropertyMetadata,
  t: (key: string) => string,
  nodeType: string
): PropertyMetadata {
  if (!prop.name) return prop;
  const titleKey = `nodes:${nodeType}.properties.${prop.name}.title`;
  const descKey = `nodes:${nodeType}.properties.${prop.name}.description`;
  // i18n.t returns the key itself when missing; we want to fall back to original.
  const titleTr = t(titleKey);
  const descTr = t(descKey);
  return {
    ...prop,
    title: titleTr === titleKey ? prop.title : titleTr,
    description: descTr === descKey ? prop.description : descTr
  };
}

function translateNode(
  meta: NodeMetadata,
  t: (key: string) => string
): NodeMetadata {
  const titleKey = `nodes:${meta.node_type}.title`;
  const descKey = `nodes:${meta.node_type}.description`;
  const titleTr = t(titleKey);
  const descTr = t(descKey);
  const properties = meta.properties?.map((p) => translateProperty(p, t, meta.node_type));
  return {
    ...meta,
    title: titleTr === titleKey ? meta.title : titleTr,
    description: descTr === descKey ? meta.description : descTr,
    properties
  };
}

export function useTranslatedNodeMetadata(
  nodeType: string | undefined
): NodeMetadata | undefined {
  const metadata = useMetadataStore((s) => s.metadata);
  const { t } = useTranslation();

  return useMemo(() => {
    if (!nodeType) return undefined;
    const meta = metadata[nodeType];
    if (!meta) return undefined;
    return translateNode(meta, t);
  }, [nodeType, metadata, t]);
}

export function useAllTranslatedMetadata(): NodeMetadata[] {
  const metadata = useMetadataStore((s) => s.metadata);
  const { t } = useTranslation();

  return useMemo(
    () => Object.values(metadata).map((m) => translateNode(m, t)),
    [metadata, t]
  );
}
```

```ts
import i18n from "../i18n";

export function translateError(
  code: string,
  fallback: string,
  params?: Record<string, string | number>
): string {
  const key = `errors:${code}`;
  const translated = i18n.t(key, params ?? {});

  return translated === key ? fallback : translated;
}
```

任何 PR 修改了用户可见的英文字符串（按钮、菜单、对话框、工具提示、错误消息）时，**在同一个 PR 中**把它迁移到 i18n。
